About This Project

Problem Statement

Analysing what drives Olympic success is difficult because of the large volume of historical data from 1992 to 2026. This project uses Tableau to analyse medal achievements across nations, athlete participation, regional performance efficiency, sport-category medal distribution, and the relationship between sports investment and medal outcomes in the Summer and Winter Games.

Who It Helps

  • Olympic Committee strategists: choose high-yield sport categories to invest in.
  • Sports investment analysts: compare investment levels with medal efficiency by region.
  • Journalists & storytellers: tell data-backed stories about host advantage and trends.

Tools Used

Tableau Public (12 visualizations, 2 dashboards, 8-scene story, 7 calculated fields + 1 parameter), Python Flask, Bootstrap 5, Tableau Embedding API v3.
