# Global-Olympic-Sports-Performance-Analysis
Tableau project analyzing Olympic medal performance, regional efficiency and sports investment (1992–2026) - SkillWallet internship (Data Analytics with Tableau)

**Tableau Public:** https://public.tableau.com/app/profile/manas.geedkar/viz/GlobalOlympicSportsPerformanceAnalysis/OlympicStory

**Dataset:** https://www.kaggle.com/datasets/meruvakodandasuraj/olympic-games-performance-and-medal-history-199226

**Web Integration:** Flask app in `olympic_flask/` (`pip install flask` → `python app.py` → http://127.0.0.1:5000)
